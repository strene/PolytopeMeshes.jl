# PolytopeMeshes.jl

Generation of polytopal (Voronoi/PEBI) meshes in 2D and 3D that conform to
points, lines and surfaces. Typical uses are reservoir and subsurface grids
where cell faces should follow faults and fractures (face constraints), and
cell centers should follow wells (cell constraints).

The site-placement algorithms are a Julia port of the
[UPR module](https://github.com/rbe051/UPR) of MRST by Runar Lie Berge. The
Voronoi diagrams are computed in pure Julia by clipping each cell against
the bisectors of its nearest neighbors, so no external mesh generator or
Qhull is needed.

Meshes are returned as a `PolytopalMesh`, which can be written to VTK and
converted to `Jutul.UnstructuredMesh`.

## Quick start

```julia
using PolytopeMeshes

fault = [[[0.2, 0.2], [0.8, 0.8]]]  # face constraint (polyline)
well  = [[[0.2, 0.8], [0.8, 0.2]]]  # cell constraint (polyline or single point)

# Cartesian background grid refined around the well
G = composite_pebi_grid_2d([0.05, 0.05], [1, 1];
    face_constraints = fault, cell_constraints = well, mlqt_max_level = 1)

# Fully unstructured background grid (DistMesh)
G = pebi_grid_2d(0.05, [1, 1]; face_constraints = fault, cell_constraints = well)

G.face_tags   # fault index of each face (0 if not on a fault)
G.cell_tags   # well index of each cell (0 if not a well cell)
check_mesh(G) # closed cells, positive volumes

write_vtk("grid", G)                # cells (.vtu, polygons/polyhedra)
write_vtk_faces("grid_faults", G)   # faces on the faults

using Jutul
g = UnstructuredMesh(G)  # tags become Jutul mesh entity tags
```

In 3D:

```julia
# Triangulated surfaces as face constraints and 3D polylines as cell constraints
S = surface_triangulation([[0.2, 0.2, 0.3], [0.8, 0.3, 0.4], [0.7, 0.8, 0.7], [0.2, 0.7, 0.6]], 0.08)
G = composite_pebi_grid_3d((12, 12, 12), (1, 1, 1);
    face_constraints = [S], fc_rho = 0.08,
    cell_constraints = [[[0.9, 0.1, 0.1], [0.9, 0.9, 0.9]]])

# Hierarchical gridding of intersecting planar fractures: 1D grids of the
# intersections, 2D fracture grids conforming to them, and a 3D grid
# conforming exactly to the 2D grids.
fracs = [[[1, 3, 2], [4, 3, 2], [4, 3, 4], [1, 3, 4]],
         [[2, 2, 3.3], [5, 2, 3.3], [5, 4, 3.3], [2, 4, 3.3]]]
ints = surface_intersections_3d(fracs)
g1 = line_grid_3d(ints, 0.2)
g2 = surface_grid_3d(fracs, g1, ints, 0.25, 0.25 / 6)
G = volume_grid_3d([6, 6, 6], fracs, g2, 0.4, 0.4 / 12)
```

Plain Voronoi diagrams restricted to a domain are also available:

```julia
G = voronoi_mesh(sites, box_domain((0, 0, 0), (1, 1, 1)))
G = voronoi_mesh(sites, PolygonDomain(vertices))       # non-convex 2D polygons
G = voronoi_mesh(sites, convex_hull_domain(points))    # convex 3D domains
G, sites = centroidal_voronoi_mesh(sites, domain; density = x -> 1.0)
```

See the `examples` folder for the UPR examples ported to Julia.

## Triangulation backends

The background sites of `pebi_grid_2d`, the 2D fracture grids of
`surface_grid_3d` and the triangulations of `surface_triangulation` are
generated by an interchangeable backend, selected with the `triangulation`
keyword. The default is `DistMeshBackend()`, which uses
[DistMesh.jl](https://github.com/juliageometry/DistMesh.jl):

```julia
G = pebi_grid_2d(0.05, [1, 1]; face_constraints = fault,
    triangulation = DistMeshBackend(maxit = 500))
```

A backend is a subtype of `TriangulationBackend` with a method of
`triangulate_polygon(backend, polygon, size, fixed; rng, min_size)` that
returns `(points, triangles)`, with the `fixed` points first and in the given
order. Points outside the polygon and degenerate triangles are removed by
PolytopeMeshes. Backends that depend on other packages, such as Gmsh.jl or
Meshes.jl, are meant to be added as package extensions: the backend type is
declared in PolytopeMeshes, and the method is defined in an extension that
loads when the package is loaded:

```julia
# src/triangulation/gmsh.jl (in PolytopeMeshes)
struct GmshBackend <: TriangulationBackend
    # options
end

# ext/PolytopeMeshesGmshExt.jl
module PolytopeMeshesGmshExt
using PolytopeMeshes, Gmsh
function PolytopeMeshes.triangulate_polygon(b::GmshBackend, polygon, size, fixed; rng, min_size)
    # mesh the polygon with the fixed points embedded and the size field
    # given by `size`, then put the fixed points first
    return points, triangles
end
end
```

Custom backends can be defined the same way in user code.

## Mesh format

`PolytopalMesh{D}` stores faces with node lists and neighbor pairs
`(l, r)` (`r == 0` on the boundary), and cells as lists of faces, in the same
layout as MRST and Jutul. Face nodes are ordered so that the normal points
from `l` to `r` (out of the domain on the boundary). The Voronoi site of each
cell is kept in `cell_sites`, and `boundary_tags` tells which domain facet a
boundary face lies on. Use `mesh_geometry(G)` for volumes, centroids, areas
and normals.

Differences from UPR:
- Options are keyword arguments in snake case (`CCFactor` → `cc_factor`,
  `faceConstraints` → `face_constraints`, `polyBdr` → `polygon`, ...).
- Cell and face tags hold the index of the constraint instead of a boolean.
- Face constraints crossing each other share circles at the intersection,
  and conflicts are resolved by shrinking or merging circles, following
  UPR's `fixIntersections`. Intersections at very acute angles may still
  lose conformity, and this is reported as a warning.
- `centroidal_voronoi_mesh` uses Lloyd iterations instead of L-BFGS on the
  CPG energy (same fixed point).
- `composite_pebi_grid_3d` places the background sites at the centers of
  `celldim` Cartesian cells.
- The background points are generated by a pluggable triangulation backend,
  by default DistMesh.jl (see above). It is seeded from an `rng` keyword so
  grids are reproducible, and the `linearize` option of UPR is not available.

## Known limitations

- 3D face conformity (as in UPR) requires the surface triangulation to be
  Delaunay on the surface: no surface site may lie inside another vertex's
  ball. Structured triangulations with cocircular pairs (e.g. squares split
  into two right triangles) break this when the surface is curved, and some
  faces then do not trace the triangles. Use near-equilateral triangles, as
  `surface_triangulation` produces.
- Free surface edges get tip sites (unlike UPR) so the conforming faces stop
  at the edge. A tip is placed on the intersection circle of the two edge
  balls, rotated out of the surface plane if needed to stay inside the domain
  and outside all balls. If no such position exists (e.g. at sharp reflex
  corners or edges within a fraction of a ball radius from the domain
  boundary), that edge gets no tip and the faces there may extend up to about
  one ball radius beyond it.
- Voronoi cells of non-convex 2D domains are clipped against the domain
  polygon. A cell that would be split into two parts by a concave corner is
  not handled.
